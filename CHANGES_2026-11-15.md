## 9. Verifizierung

Nach `xcodegen generate` sollten folgende Schemes verfügbar sein:
- `iMailSecure` (iOS)
- `iMailSecure-macOS` (macOS)

Build-Test:
```bash
# iOS
xcodebuild -scheme iMailSecure -destination 'platform=iOS Simulator,name=iPhone 17' build

# macOS
xcodebuild -scheme iMailSecure-macOS -destination 'platform=macOS' build
```

Beide Schemes bauen (Stand 2026-11-15). Damit das macOS-Target die
gemeinsamen Quellen übersetzen kann, wurden die iOS-spezifischen Stellen
hinter `#if os(...)` gelegt und in `Utilities/PlatformSupport.swift`
gebündelt:

| Stelle | iOS | macOS |
|---|---|---|
| Navigationstitel | `.inline` | unverändert |
| Tastatur | `keyboardType` | ohne Wirkung |
| Großschreibung | `.never` | ohne Wirkung |
| Toolbar | `topBarLeading/Trailing` | `navigation` / `primaryAction` |
| Flächenfarbe | `secondarySystemBackground` | `controlBackgroundColor` |
| Externer Link | `UIApplication.open` | `NSWorkspace.open` |
| Teilen | `UIActivityViewController` | `NSSharingServicePicker` |
| HTML-Höhe | KVO auf `contentSize` | `document.body.scrollHeight` |
| App-Lebenszyklus | `UIApplication`-Notifications | `scenePhase` |
| CoreData-Schutz | `FileProtectionType.complete` | FileVault (kein Schlüssel) |

Offen für macOS: eigene Menüs, Settings-Szene, Toolbar-Feinschliff (siehe
Punkt 7 der nächsten Schritte).
